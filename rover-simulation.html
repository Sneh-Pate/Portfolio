System Specifications

Hardware & Structural Components

  • Microcontroller: ESP32-S3 board serving as the main control unit
  • Chassis & Drivetrain: Custom 3D-printed chassis with 3D-printed wheels and axles
  • Drive System: Onboard drive motors managing rover movement and mobility
  • Power Source: Onboard battery pack delivering mobile power to the system

Sensing & Sorting System

  • Color Detection: RGB color sensor positioned to read incoming marble colors
  • Sorting Mechanism: Servo-driven scoop that rotates to route each marble into its matching bin

Software & Firmware Setup

  • Development Environment: Coded in C++ using the Arduino IDE for the ESP32-S3 platform
  • Visual Indicators: Custom C++ code using the Adafruit_NeoPixel library to illuminate LEDs for real-time status and color-matching feedback
